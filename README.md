# 🌍 WanderLust

WanderLust is a full-stack travel and accommodation web application that allows users to explore, view, and manage travel listings.

## ✨ Features

* 🏠 Browse travel and accommodation listings
* 🔍 View detailed information about each listing
* ➕ Create, edit, and delete listings
* 🔐 User authentication and authorization
* ⭐ Add reviews and ratings
* 📍 Location-based listing information
* 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript, EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Passport.js
* **Templating:** EJS

## 🚀 Getting Started

```bash
git clone <your-repository-url>
cd WanderLust
npm install
npm start
```

Create a `.env` file and add your MongoDB connection string and required environment variables.

WanderLust aims to provide a simple platform for discovering and managing travel stays while demonstrating practical full-stack web development using the MERN/Node.js ecosystem.
